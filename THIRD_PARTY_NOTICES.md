# Third Party Notices

Начальный архив содержит skeleton-код и конфигурации для следующих технологий:

- PHP
- Symfony Components
- PostgreSQL
- MySQL / MariaDB
- Redis
- RabbitMQ
- Vue
- Nuxt
- TypeScript
- OpenAPI
- Prometheus
- OpenTelemetry

Фактические лицензии зависимостей фиксируются после установки пакетов через Composer, pnpm, pip, Gradle или другой пакетный менеджер.

## SSH transport (0.4.5)

- Paramiko 5.x — LGPL-2.1, https://pypi.org/project/paramiko/ (внешняя Python-зависимость, не включена в архив исходников).
- Cryptography, bcrypt, PyNaCl и Invoke — транзитивные зависимости, лицензии и версии фиксируются в установленном окружении.
